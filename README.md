# Lounassää

Seinälle kiinnitettävä sää- ja lounasnäyttö (Galaxy Tab A11+). Lukee RuuviTag-anturit Bluetooth LE:llä.

Tämä on laitetestiversio: oikeudet, taustapalvelu, anturien tallennus, näytönsäästäjä ja yösammutus.
Pakettinimi: `fi.lounassaa.app`.

APK:t löytyvät Releases-sivulta (jokainen push `main`-haaraan rakentaa uuden).
